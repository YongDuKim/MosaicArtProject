# モザイク生成アルゴリズム

実装は `src/lib/mosaic.ts`。

1. 入力画像を `x` (既定5) で割ったグリッドに分割
2. 各セルの平均色に RGB 二乗距離が最も近いタイル画像を選択 (タイルは 256px で保持し、貼り付け前に `n` px へ段階的縮小する)
3. 0/90/180/270 度のランダム回転で貼り付け (OFF 可)
4. 色補正スライダーで、ディテールを保ったままセル目標色へ色シフト
5. タイル解像度 `n` は偶数のみ。奇数だとタイル境界が JPEG のクロマ格子 (4:2:0 の2px) とずれ、原寸 JPG のファイルサイズが1割ほど増える (実測: n=25 と 27 が、24・28・32 より1ピクセルあたり 6〜10% 大きい)
6. 出力サイズは「グリッド数 × タイル解像度 `n` (既定24) px」。端末のキャンバス上限を超える場合は `n` を自動縮小する (このときも偶数に切り下げる。上限値は [architecture.md の設計原則](architecture.md) を参照)
7. 出力キャンバスを Worker 内で JPG (既定) または PNG にエンコードする。JPG の品質は `src/lib/format.ts` の `JPEG_QUALITY` 固定。JPG は書き出し解像度のプリセット (低 2,048px / 中 4,096px / 高 縮小なし) に従い、エンコード直前に段階的縮小で長辺を合わせる。PNG は常に原寸
