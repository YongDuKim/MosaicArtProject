# モザイク生成アルゴリズム

実装は `src/lib/mosaic.ts`。

1. 入力画像を `x` (既定5) で割ったグリッドに分割
2. 各セルの平均色に RGB 二乗距離が最も近いタイル画像を選択
3. 0/90/180/270 度のランダム回転で貼り付け (OFF 可)
4. 色補正スライダーで、ディテールを保ったままセル目標色へ色シフト
5. 出力サイズは「グリッド数 × タイル解像度 `n` (既定25) px」。端末のキャンバス上限を超える場合は `n` を自動縮小 (上限値は [architecture.md の設計原則](architecture.md) を参照)
6. 出力キャンバスを Worker 内で JPG (既定) または PNG にエンコードする。JPG の品質は `src/lib/format.ts` の `JPEG_QUALITY` 固定
