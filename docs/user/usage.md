# 使い方

1. モザイク化したい元画像をアップロード
2. タイルにする写真を複数枚アップロード (中央が正方形に切り抜かれます)
3. 配色の解析が終わったら、仕上がりとパラメータを選んで「モザイクアートを生成」
4. 生成された画像 (JPG または PNG) と使用統計をダウンロード

タイル画像はメモリ上にのみ保持され、ページをリロードすると消えます。元画像・素材・グリッド解像度を変更すると、ブラウザ内で配色を解析し直します。

## 仕上がりと写真の色補正

| モード   | 優先すること                     | 素材に近い色がない場合                                 |
| -------- | -------------------------------- | ------------------------------------------------------ |
| 色を優先 | 元画像の各部分との色の近さ       | 元の色との違いが小さいタイルを選びます                 |
| バランス | 元の色の印象と、明暗・境界の再現 | 素材の配色への部分的な置き換えを許します               |
| 形を優先 | 明暗の構成と、領域の区別         | 素材の明暗・色味の幅を使うように、全体の配色を変えます |

初期のモードは「色を優先」です。「形を優先」では、たとえば黒い被写体と灰色の背景を、紺色と明るい青で表現できます。置き換え先の色はアップロードした素材から決まり、黒から青という対応に固定されていません。

「タイル写真の色補正」は、選んだ写真をモードの目標色に近づける強さです。初期値の0%では写真の色を変更せず、配色と配置で表現します。「形を優先」で紺色を目標にした場所は、補正を上げても元画像の黒には戻さず、紺色へ近づけます。補正を強めると写真の色の印象も変わります。

モードはグリッドの代表色と隣接セルの関係を扱います。写真内部の輪郭を被写体の輪郭に合わせる機能ではありません。素材の明暗と色味がほとんど同じ場合、どのモードでも再現に限界があります。素材を増やす、色優先と比較する、写真の色補正を上げるといった調整ができます。

## 3モードの比較と拡大表示

「3モードを比較」は、同じ元画像・素材・グリッド・色比較方式・補正・ばらつき・回転・出力設定で3つの結果を生成します。まず色補正とばらつきを0、回転をOFFにすると、モードによる違いを確認しやすくなります。ばらつきや回転を有効にした比較でも、3モードには同じ乱数列を使います。

結果の上のボタンでモードを切り替えます。「表示倍率」で全体・2倍・4倍・原寸を選び、拡大後はスクロールして写真を確認できます。モードを切り替えても位置と倍率を保ちます。拡大しても、出力時のタイル解像度を超える細部は増えません。

ダウンロードと使用統計は表示中の結果に対応します。仕上がりモード以外の生成設定、元画像、素材を変更すると結果を破棄するため、残したい画像は変更前にダウンロードしてください。比較は通常の1モード生成より処理時間と結果の保持に使うメモリが増えます。

## 色比較とばらつき

「タイルの色比較方式」は、目標色への近さの測り方です。仕上がりの3モードとは独立して選べます。配色解析と隣接セルの関係評価には、どちらの方式でも Oklab を使います。

| 方式  | 比較するもの               | ばらつきの範囲 | 初期値 | 刻み  |
| ----- | -------------------------- | -------------- | ------ | ----- |
| RGB   | RGB の数値の近さ           | 0〜50          | 10     | 1     |
| Oklab | 見た目の明るさ・色味の近さ | 0〜0.1         | 0.01   | 0.001 |

初期の方式は RGB です。「色を優先」のばらつきは、元画像の各部分への色の距離が、最小距離に設定値を加えた範囲内の候補からランダムに選ぶ設定です。0なら常に最も近い1枚を使います。

「バランス」「形を優先」では、目標色への近さと周囲との明暗・色味の関係を合わせて評価します。ばらつきが0ならその評価で最良の候補を選び、値を上げると近い評価の候補からランダムに選びます。写真の種類を増やせる一方、明暗や境界の再現が弱まる場合があります。

ばらつきは方式ごとに尺度が異なり、同じ数値で同じ強さにはなりません。モードが異なる場合も同じ見た目のばらつきにはなりません。調整値は色比較方式ごとに保持されるため、切り替えて戻ると元の値に戻ります。ページをリロードすると初期値に戻ります。

## 注意事項

- iPhone などのスマートフォンでは、一度に大量の写真を選ぶと iOS の写真ピッカーが「写真を読み込めません」などのエラーを出すことがあります。**20〜30枚ずつ数回に分けて追加**してください。
- タイルは追加方式で読み込まれます。同じ写真 (ファイル名とサイズが同一) を再選択しても自動的にスキップされるため、分割して追加しても重複しません。「タイルをすべて削除」ボタンでやり直せます。
- タイルのデコードは Web Worker で行われるため、枚数が多く読み込みに時間がかかっても画面は固まりません (200枚・12MP 写真での動作を確認済み)。
- HEIC/HEIF (iPhone の写真形式) は、ブラウザが対応していない場合でもアプリ内で自動的に変換して読み込みます。それでも読めない形式や破損ファイルはスキップされ、ファイル名が表示されます。
- タイル解像度 `n` は偶数のみ選べます。奇数にすると JPG のファイルサイズが1割ほど増えるためです。
- 出力形式は JPG と PNG から選べます。既定は JPG です。モザイクアートは写真を敷き詰めた画像のため、PNG では出力が数百 MB になることがあります。**画質の劣化を避けたい場合のみ PNG** を選んでください。
- JPG を選んだときは、書き出す解像度を 低 (長辺 2,048px) / 中 (4,096px) / 高 (縮小なし) から選べます。モザイクの生成そのものは常に原寸で行い、JPG に変換する直前に縮小するため、解像度を下げてもタイルの配置や色は変わりません。ダウンロードするファイルを軽くしたいときに使ってください。
- [設計上の制約](../internal/architecture.md)により、出力サイズの上限は PC では1辺 16,384px、スマートフォンでは1辺 4,096px です。上限を超える場合はタイル解像度 `n` が自動的に縮小されます。
